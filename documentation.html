Подключение TokenClub API

Пошаговое руководство для настройки совместимого клиента через Custom Endpoint.

1. Получите данные доступа

Напишите в Telegram, какой объём токенов вам нужен: 1, 2, 4 или 6 млн. После оплаты вы получите адрес endpoint и персональный API-ключ. Бесплатный аккаунт можно получить после подписки на YouTube-канал.

2. Настройте клиент

В настройках приложения выберите Custom Endpoint или OpenAI-compatible API и укажите полученный адрес. В поле API Key вставьте персональный ключ.

Base URL: https://api.tokenclub.dev/v1
Authorization: Bearer ВАШ_API_КЛЮЧ

3. Выберите модель

Выберите доступную в тарифе модель и отправьте тестовый запрос.

4. Безопасность и поддержка

При подозрении на компрометацию ключа прекратите его использование и напишите в Telegram. Не указывайте ключ целиком в обращении.
